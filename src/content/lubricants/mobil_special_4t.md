## 产品概述

美孚万能™ 4T（Mobil Special 4T）是一款通用性能的四冲程摩托车发动机油, 专为润滑小型四冲程发动机而设计。该产品采用高度精炼的矿物基础油和精心平衡的添加剂配方, 能够有效防止沉积物形成, 同时提供优异的抗磨损和防腐蚀保护。

### 核心优势

**1. 有效的抗磨损保护**
- 延长发动机使用寿命
- 减少关键部件磨损
- 降低维护成本

**2. 卓越的热稳定性和氧化稳定性**
- 保持发动机内部清洁
- 防止油泥和沉积物积累
- 确保平稳可靠的操作性能

**3. 出色的防腐蚀保护**
- 保护发动机关键部件
- 防止锈蚀和腐蚀
- 延长油品使用寿命

### 4. 防腐蚀保护

专门的防锈防腐蚀添加剂:

## 使用建议

### 换油周期

**正常工况: **
- 建议每 3,000-5,000 公里或 6 个月更换一次
- 以先到者为准

**恶劣工况（缩短至70%）: **
- 频繁短途行驶（单程少于10公里）
- 长期重载或高转速运行
- 多尘或极端温度环境
- 建议每 2,000-3,500 公里更换

### 用量参考

不同车型的机油容量差异较大, 请参考车辆用户手册: 
- 小型摩托车: 通常 0.8-1.2 升
- 中型摩托车: 通常 1.0-1.5 升
- 割草机/发电机: 通常 0.4-0.8 升

**注意: ** 实际用量请以车辆制造商规定为准。

### 使用注意事项

1. **确认粘度等级**
   - 检查车辆手册推荐的粘度等级
   - 20W-40 适合大多数温暖气候地区

2. **定期检查油位**
   - 每次使用前检查机油尺
   - 确保油位在正常范围内

3. **正确更换流程**
   - 热车后放油（便于排出杂质）
   - 同时更换机油滤清器（如配备）
   - 加注新油后检查是否有泄漏

4. **储存条件**
   - 存放在阴凉干燥处
   - 避免阳光直射和高温
   - 密封保存, 防止污染

## 常见问题

### Q1: 美孚万能 4T 可以用于汽车发动机吗？
**A:** 不建议。美孚万能 4T 是专门为四冲程摩托车和小型发动机设计的, 其配方与汽车发动机油不同。摩托车发动机通常与变速箱共用机油, 需要特殊的摩擦特性。请使用专为汽车设计的发动机油。

### Q2: 20W-40 粘度等级适合什么气候？
**A:** 20W-40 是一种多级粘度油, 适合温暖气候地区全年使用。"20W"表示低温流动性, 可在-15°C以上正常启动；"40"表示高温粘度, 适合正常工作温度。在极寒地区（低于-15°C）, 建议选择更低粘度的油品如10W-30或5W-30。

### Q3: API SG 标准是否过时？
**A:** API SG 是较早期的汽油发动机油标准（1993年发布）, 但对于小型四冲程摩托车和通用小型发动机来说, SG 级别仍然完全适用。这些发动机的工作条件和设计要求不需要更高规格的油品。对于现代高性能摩托车, 可能需要更高级别的油品（如 API SN 或 JASO MA/MA2）。

### Q4: 可以与其他品牌的摩托车机油混用吗？
**A:** 虽然短期内混合使用不会立即造成损坏, 但不建议这样做。不同品牌的机油可能使用不同的添加剂配方, 混合后可能影响性能。最好排空旧油后再加入新品牌的机油。

### Q5: 如何判断机油是否需要更换？
**A:** 可以通过以下方式判断: 
- 里程数达到厂家规定的换油周期
- 机油颜色变黑且粘稠
- 发动机噪音增大或动力下降
- 机油液位异常降低
- 定期保养时间到期

### Q6: 美孚万能 4T 可以用于二冲程发动机吗？
**A:** 不可以。美孚万能 4T 是专为四冲程发动机设计的。二冲程发动机需要使用专门的二冲程机油（通常标注为 2T 或 Two-Stroke）, 两者不能互换使用。
