- **保持粘度稳定**：长期使用粘度变化小

- **潮湿环境保护**：特别适合多雨潮湿地区

- 建议：每3,500-5,000公里或6个月更换

### 用量参考

不同车型的机油容量差异较大：

| 车型类别 | 典型用量 |
|---------|---------|
| 小型轿车（1.0-1.6L） | 3.0-4.0升 |
| 中型轿车（1.8-2.5L） | 4.0-5.0升 |
| 大型轿车/SUV（2.5L以上） | 5.0-6.5升 |
| 微型车（<1.0L） | 2.5-3.5升 |

**注意：** 实际用量请以车辆用户手册规定为准, 更换机油滤清器时需额外增加0.3-0.5升。

### 换油流程建议

1. **热车放油**
   - 行驶5-10分钟使机油升温
   - 热油流动性好, 能带出更多杂质
   - 注意安全, 避免烫伤

2. **更换机油滤清器**
   - 每次换油必须更换机滤
   - 选择原厂或知名品牌机滤
   - 安装前在密封圈涂少量新油

3. **加注新油**
   - 使用漏斗避免洒漏
   - 先加入推荐用量的80%
   - 启动发动机运转1-2分钟
   - 熄火等待5分钟后检查油位
   - 补充至油尺上限和下限之间

4. **检查泄漏**
   - 检查放油螺丝是否拧紧
   - 检查机滤接口是否漏油
   - 地面是否有油渍

5. **记录保养信息**
   - 记录换油日期和里程
   - 记录使用的机油品牌和型号
   - 设置下次保养提醒

## 常见问题

### Q1: 美孚力霸系列和美孚1号有什么区别？
**A:** 美孚力霸是矿物基础油或半合成油, 定位经济实用；美孚1号是全合成高端油, 性能更卓越。力霸适合日常使用和性价比追求者, 1号适合高性能车和极致保护需求。

### Q2: 5W-30和10W-40哪个更好？
**A:** 没有绝对的好坏, 关键看适用性：
- 5W-30：低温启动更好, 燃油经济性略优, 适合寒冷地区和新款车型
- 10W-40：高温保护更强, 油膜更厚, 适合温暖地区和老款车型
请根据车辆手册推荐、当地气候和车况选择。

### Q3: API SM标准是否过时？
**A:** API SM是2004年发布的标准, 虽然不是最新标准（目前有SN、SP）, 但对于大多数普通家用车来说完全够用。SM级别仍被广泛使用, 特别是在经济型机油市场。如果您的车辆手册要求SM或更低级别, 美孚力霸完全满足要求。

### Q4: 可以混用不同粘度的美孚力霸吗？
**A:** 不建议长期混用。短期应急可以, 但最好排空旧油后加入正确粘度的新油。不同粘度的油品配方可能有差异, 混用可能影响性能。如果必须混用, 尽量选择同一品牌同系列产品。

### Q5: 美孚力霸可以用于涡轮增压发动机吗？
**A:** 可以, 但需注意：
- 轻度增压车型：10W-40通常足够
- 高性能增压车型：建议使用更高规格的合成油
- 务必查阅车辆手册要求
- 涡轮增压发动机工作温度更高, 对油品要求更严格

### Q6: 如何判断机油是否需要更换？
**A:** 可通过以下方式判断：
- 里程数达到厂家规定周期
- 使用时间超过6个月
- 机油颜色变黑且粘稠
- 机油气味异常（焦糊味）
- 发动机噪音增大或动力下降
- 机油液位异常降低
- 定期保养提醒到期

### Q7: 美孚力霸适合CNG/LNG车辆吗？
**A:** 是的, 美孚力霸系列明确标注适用于使用汽油、压缩天然气（CNG）或液化天然气（LNG）的乘用车。这些替代燃料燃烧特性与汽油略有不同, 美孚力霸的配方能够提供适当的保护。

### Q8: 冬季必须使用5W-30吗？
**A:** 不一定。选择取决于当地最低气温：
- 最低温>-15°C：10W-30或10W-40也可使用
- 最低温-15°C至-25°C：建议使用5W-30
- 最低温<-25°C：可能需要0W系列
请参考车辆手册和当地气候条件选择。

- 避免吸入油雾或蒸汽
- 穿戴适当的工作服和手套

**环保处理：**
- 废弃机油属于危险废物
- 请勿随意倾倒或排放
