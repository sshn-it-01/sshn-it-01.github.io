# 抗燃液压油是什么？磷酸酯型与水-二元醇型怎么选

> **一句话答案**: 设备靠近明火、高温熔融物或热源时, 应考虑抗燃液压油。主流两类是**磷酸酯型 HFD**与**水-二元醇型 HFC**: 前者耐高温、自熄, 后者靠含水量防火但温度上限较低。

## 一、什么场合必须用抗燃液压油

冶金、锻造、压铸、蒸汽轮机 EH 控制系统, 以及压铸机、冲压机、熔炉开门器、钢包倾动机构和玻璃拉丝机械等设备, 存在喷油接触高温表面或明火的风险, 应按设备厂家要求选择抗燃液压油。

## 二、两大类抗燃液压油

| | 磷酸酯型（HFD） | 水-二元醇型（HFC） |
|---|---|---|
| 抗燃原理 | 基础油难燃、可自熄 | 含水量吸热防火 |
| 温度适应性 | 耐高温 | 整体液温通常不宜超过 65℃ |
| 代表产品 | 美孚派路特 HFD 46B | 美孚纽华 FR 200D |
| 典型场合 | 汽轮机 EH、冶金、锻造 | 压铸机、冲压机、熔炉开门器 |

第一道分岔是温度: 长期超过 65℃ 时不能按水-二元醇型处理, 必须结合设备规范选择更适合的体系。

## 三、美孚派路特 HFD 46B

该产品是磷酸酯型抗燃液压油, ISO VG 46, 40℃ 运动黏度 43.5 厘斯, 闪点 258℃, 获 FM 全球认证级别 6930。

换用前必须确认四件事: 系统运行温度；从矿物油或水-乙二醇液切换时执行冲洗；核对密封件相容性；核对油漆相容性。该产品不推荐与氯丁橡胶、丁腈橡胶及硅材料密封件同用, 可与丁基橡胶、氟橡胶等材料相容。

## 四、美孚纽华 FR 200D

该产品是水-二元醇型, 40℃ 运动黏度 41.5 厘斯, 黏度指数 175, 倾点 -30℃, FM Global 认可。其防火特性依赖约 38% 的含水量；因蒸发失水导致黏度升高时, 可按厂家方法加入脱离子水修正, 但不适用于整体液温超过 65℃ 的系统。

它与常见液压系统材料相容, 但聚氨酯、皮革或软木部件除外。两种不同体系不能混用。

## 五、常见问题

**抗燃是不是不怕火？** 不是。抗燃液压油是降低燃烧风险、便于控制, 不能替代防火设计。

**换成抗燃油要做什么？** 必须核查密封件、软管与油漆相容性, 并按厂家要求冲洗系统。
